# Third-party data notices

The computations use established prime-gap and first-occurrence data. Inclusion or citation of these materials does not imply that Riccardo Panza originated the underlying prime-gap records.

## Prime Gap List Project

`sources/gap_snapshot.csv` is a compact extract derived from the Prime Gap List Project's public `allgaps.sql` dataset. `sources/boundary.html` is a frozen copy of its published complete-search boundary page. Source URLs, access dates and SHA-256 checksums are recorded in `output/provenance.csv`.

- <https://github.com/primegap-list-project/prime-gap-list>
- <https://primegap-list-project.github.io/fully-analyzed/>

The project repository did not contain a root `LICENSE` file when this release was prepared. These source extracts are therefore excluded from this repository's MIT and CC BY licensing grants. Users should consult the source project before redistributing them separately.

## OEIS Foundation

`sources/oeis_*.txt` are frozen B-file extracts from OEIS sequences A002386, A000101, A000230 and A014321. The paper also cites A005250 and A053695. OEIS attribution and current reuse terms apply.
