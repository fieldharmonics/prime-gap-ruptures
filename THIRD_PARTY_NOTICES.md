## Prime Gap List Project

`sources/gap_snapshot.csv` is a compact numerical extract derived from the Prime Gap List Project's public `allgaps.sql` dataset. It contains numerical gap facts and source status flags, not the source's prose, discovery-credit text or website design. `sources/boundary.md` is an author-written factual summary of the complete-search boundary. The former HTML copy is omitted from this corrected package, though it remains in earlier Git history. Source URLs, access dates and SHA-256 checksums are recorded in `output/provenance.csv`.
